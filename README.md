# Yotion

노션과 유사한 문서 작성·페이지 정리 경험을 자체 코드로 구현하는 독립 웹앱입니다. 현재는 계정 없이 이 기기에서 사용하는 로컬 작업 공간을 제공합니다.

## 실행

Node.js 22.12 이상과 npm이 필요합니다. 개발·자동 검증 환경은 macOS / Node.js 26.4.0 / Chromium 156입니다.

```sh
npm ci
npm run dev
```

http://127.0.0.1:3000 에서 작업 공간을 엽니다. 포트가 사용 중이면 콘솔에 표시된 주소를 사용합니다. 외부 계정, 노션 연결, DB 서버, 환경 변수는 필요하지 않습니다.

## 작업 화면

- 사이드바 페이지 트리, 하위 페이지, 경로, 즐겨찾기, 페이지 복제·이동·휴지통·복원. 페이지를 드래그하여 다른 페이지 아래로 이동할 수 있습니다. 메뉴의 ‘이동’으로도 조작합니다.
- 제목, 이모지 아이콘, 자체 그라디언트 커버, 글꼴·전체 너비·작은 본문, 라이트·다크·시스템 테마, 사이드바 너비 조절.
- `/` 명령과 검색·방향키·Enter·Escape. 제목 1~3, 목록, 체크박스, 토글, 인용, 코드, 구분선, 단순 표, 이미지.
- 텍스트 선택 시 서식 도구, Markdown 입력 규칙, undo/redo. 블록 핸들의 이동·복제·삭제, 단일 최상위 블록 드래그, Alt+Shift+↑↓ 이동.
- 본문 최상위 블록과 사이드바·즐겨찾기 페이지의 우클릭 메뉴. 클릭한 대상의 이동·복제·삭제 등을 실행하며, 현재 열려 있지 않은 페이지도 처리합니다. Shift+F10으로 메뉴를 열고 방향키·Enter로 실행, Escape·Tab으로 닫을 수 있습니다.
- 제목·본문 검색: Cmd/Ctrl+K, 방향키·Enter로 탐색.
- 페이지별 자동 저장, 저장 상태, 실패·재시도, 두 탭 revision 충돌 차단. Cmd/Ctrl+S로 즉시 저장합니다.
- 페이지 JSON 내보내기·새 페이지로 가져오기(최대 2 MiB). 작업 공간 JSON은 최대 20 MiB까지 계층을 유지해 새 사본으로 가져옵니다. 기존 페이지는 유지합니다.

작업 공간은 브라우저 **IndexedDB**에 저장하며 정상 편집 후 약 600ms 뒤 저장을 시작합니다. 저장 완료 표시는 트랜잭션 완료 후에만 표시합니다. 다른 탭의 변경과 충돌하면 자동 덮어쓰기를 중단하고 현재 변경 다운로드·저장본 교체를 제공합니다. 여러 페이지를 포함한 작업 공간 전체 단위로 충돌을 판단하므로 서로 다른 페이지를 편집해도 충돌할 수 있습니다.

브라우저 데이터 삭제 시 문서도 삭제됩니다. 다른 기기 동기화·서버 저장·계정·권한·협업은 구현하지 않았습니다. 이미지는 PNG/JPG/WebP/GIF/AVIF 1 MiB 이하를 문서 내부 데이터로 보관합니다. 작업 공간은 최대 1,000페이지, 문서는 2 MiB / 20,000노드 / 중첩 64단계까지 지원합니다. 표는 일반 문서 표이며 데이터베이스가 아닙니다.

실제 한글 IME, Windows·Edge, 노션과의 픽셀·키보드 동등성 검증은 남아 있습니다. 이 단계는 문서 MVP 출시나 노션 전체 기능 호환을 의미하지 않습니다.

## 검증

```sh
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

개발 서버가 실행 중이면 해당 주소를 재사용합니다.

```sh
PLAYWRIGHT_BASE_URL=http://127.0.0.1:3001 npm run test:e2e
```

별도 주소를 지정하지 않으면 3017번에서 시험 서버를 시작합니다. 브라우저 시험의 데스크톱·다크·모바일·슬래시 메뉴 캡처는 `test-results/`에 생성합니다.

## 실험실과 설계 자료

`/lab`에서 기존 편집 엔진·드롭·클립보드 실험을 계속 사용할 수 있습니다. 실험 문서는 별도의 localStorage 수동 저장본을 사용하며 메인 작업 공간과 공유하지 않습니다. 기존 저장 키를 삭제하거나 자동 이전하지 않습니다. 기존 실험 문서를 JSON으로 내려받아 메인 작업 공간에 새 페이지로 가져올 수 있습니다.
