## 4. 문서 MVP 출시 체크리스트

- [ ] 노션 미연결 상태에서 신규 계정 생성부터 백업까지 완료한다.
- [ ] 지원 블록의 입력·변환·저장·복원 회귀 시험을 통과한다.
- [ ] 한글 IME, 선택, Enter, Backspace, 들여쓰기, undo/redo를 확인한다.
- [ ] 새로고침·네트워크 단절·재시도·두 탭 충돌 시 문서가 유실되지 않는다.
- [ ] 페이지 이동·삭제·복원 후 계층과 링크가 유지된다.
- [ ] 가져오기 미지원·부분 성공·실패를 사용자에게 표시한다.
- [ ] ZIP·HTML·원격 파일 입력의 위험 사례를 차단한다.
- [ ] 다른 워크스페이스 문서·파일·작업에 접근할 수 없다.
- [ ] 고정된 검증 환경에서 입력·로딩·검색 성능을 측정한다.
- [ ] 새 환경에서 DB·첨부파일 백업 복원 시험을 통과한다.
- [ ] 배포·마이그레이션·복구 절차와 알려진 제약을 문서화한다.
- [ ] 출시를 막는 데이터 유실·권한·복원 문제가 없다.

## 5. 첫 개발 묶음의 결과물

첫 구현 목표는 REA-02와 SPIKE-01이다. 드롭·클립보드 관찰 화면과 최소 편집기를 만들어 기술·호환성 불확실성을 줄인다. 이후 CORE-01부터 영구 저장과 계정 구조를 연결한다.

이 파일의 체크박스는 아직 실행·검증한 결과를 의미하지 않는다.
